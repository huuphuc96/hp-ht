Thư mục này đang chứa 16 ẢNH TẠM (hoa lá pastel vẽ sẵn) để website không bị lỗi 404.

Khi có ảnh cưới thật, chỉ cần GHI ĐÈ lên đúng tên file dưới đây — không phải
sửa code gì cả:

  groom.jpg        ảnh chú rể       (dọc, tỉ lệ 3:4, vd 900x1200)
  bride.jpg        ảnh cô dâu       (dọc, tỉ lệ 3:4)
  story-1.jpg      ảnh timeline 1   (ngang, 4:3, vd 1200x900)
  story-2.jpg  ... story-5.jpg
  gallery-1.jpg    album ảnh        (ngang hoặc dọc đều được)
  gallery-2.jpg ... gallery-8.jpg
  share.jpg        ảnh hiện khi chia sẻ link (1200x630)

Muốn thêm/bớt ảnh album: sửa danh sách `gallery` trong js/config.js.

Mẹo:
- Nén ảnh ở tinypng.com trước khi up, mỗi ảnh nên dưới 400 KB.
- Bề ngang 1600px là dư dùng cho web.
- Tên file phân biệt chữ hoa/thường trên GitHub: Anh.JPG khác anh.jpg.
